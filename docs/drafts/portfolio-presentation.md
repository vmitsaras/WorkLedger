# Deferred Portfolio Presentation Draft

**Status:** Unnumbered draft  
**Deferred:** 2026-08-25

## Boundary

This document preserves the portfolio presentation scope that was previously numbered as Phase
13. It is not an active roadmap phase. It has no task identifiers, dependency chain, version gate,
or permission to begin implementation. The work will be numbered only after the remaining product
phases are known.

## Objective

Present the product decisions and engineering quality clearly to recruiters, collaborators, and
open-source users.

## Draft deliverables

- Astro public project site and case-study information architecture.
- Safe demo mode, demo accounts, deterministic reset, and clear data disclaimer.
- Architecture, domain, accessibility, security, and tradeoff documentation.
- Screenshots, workflow media, and example calculations.
- Public README, setup, scripts, limitations, and roadmap.

## Draft quality criteria

- A visitor understands the problem and product within the first screen.
- Demo data tells realistic employee and manager stories without exposing production-style
  secrets or sensitive details.
- Documentation explains immutable events, ledgers, Temporal semantics, scoped permissions, and
  monthly locking accurately.
- Accessibility is demonstrated with evidence rather than claimed without verification.
- Installation and local setup are reproducible.
- Media has useful text alternatives or captions and reflects coherent implemented states.
- Known limitations are direct and credible.

Scheduling, identifiers, dependencies, and a future internal version milestone remain open.
